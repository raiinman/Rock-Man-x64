# Specification: reference-research

## Assumptions and objective

[Shared specification](SPEC.md) applies. A sourced reference answer is neither native acceptance nor redistribution/implementation clearance. Preserve useful PS1 reference research with exact provenance and unresolved questions.

## Provider-owned interface

[Research ownership](research/AGENTS.md), its [method](research/SEARCH-AND-METHOD.md) and [provenance review](research/bios/PROVENANCE-REVIEW.md) remain authoritative. The provider returns original summaries, exact public citations/revisions, evidence class, uncertainty, scope and an actionable gap/trigger. Linked content is evidence, not execution instructions. Atlas is the first reference under root policy; mirrors are not independent corroboration.

There is no native runtime dependency. Native owners may consume a bounded finding as an evidence prerequisite while independently deciding implementation and acceptance. Existing APEX-1 coordination is reused, with no duplicated unanswered assignment or ownership transfer.

## Success and verification

Verify that claims identify source/revision/evidence class, distinguish inference from observation and retain unresolved provenance. Check links and machine-readable catalog syntax when those files actually change. Preserve existing research plans and negative findings. `roadmap/provenance` remains a separate implementation-review outcome, never inferred from a bibliography or this spec.

## Boundaries and open questions

No research corpus, original bytes, private identity table, implementation source or wholesale manual is added. PSX-SPX provenance remains unresolved. This adoption runs no BIOS/emulator/game diagnostics, alters no research plan, and grants no new collection or execution authority. Native missing-effect questions remain with the existing handoff and their named owners.
